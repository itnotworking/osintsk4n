Privacy

SC4N is a free threat lookup with no accounts. This page explains what happens to the domains, URLs, IP addresses, email addresses, phone numbers and file hashes you check, on the website and in the SC4N Chrome extension. Last updated October 28, 2026.

What you check

When you run a lookup, the indicator you entered is sent to SC4N's server. To build the result, SC4N sends that indicator to the threat intelligence services it queries. Those services receive only the indicator from SC4N's server, not your browser, your IP address or anything that identifies you.

For domains and URLs that haven't been scanned in the last day, SC4N asks a page scanning service to take a fresh screenshot. That scan is unlisted: it isn't published, and only SC4N and the scanning service's vetted security customers can see it. Before it's sent, SC4N removes query strings and fragments, and it doesn't send links whose path looks like it contains an email address or a token automatically.

What SC4N keeps

  • No accounts, no cookies, no analytics and no advertising.
  • Lookup results are held in the server's memory for up to 30 minutes so a repeat lookup is fast, then discarded. They are not written to a database.
  • The addresses sent for automatic page scans are held in memory for 24 hours, so the same page isn't scanned twice.
  • Your recent searches are stored only in your own browser, and the Clear button on the site removes them.
  • Your IP address is held in memory for a minute or two to enforce the rate limit, and the hosting provider keeps standard request logs (such as IP address, time and page requested) for security and operations.

The SC4N Chrome extension

  • It sends nothing until you ask it to check something, by typing it into the popup, pressing Check this site, or choosing Check with SC4N from the right-click menu.
  • It then sends only that item to sc4n.lol, or opens the full report on sc4n.lol in a new tab.
  • For links and pages it removes the query string and fragment first, and for Check this site it sends only the site's name.
  • It doesn't read the pages you visit, track your browsing, or store anything about you.
